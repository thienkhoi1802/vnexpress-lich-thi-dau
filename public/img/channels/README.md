# Logo kênh phát sóng

Đặt file logo chính thức vào thư mục này (ưu tiên SVG, nếu không có thì PNG nền trong suốt, cao tối thiểu 48px).
Tên file (không phân biệt SVG/PNG):

| Tên file | Hiển thị cho kênh |
|---|---|
| `fpt-play.svg` | FPT Play |
| `tv360.svg` | TV360 |
| `k-plus.svg` | K+ / K+ SPORT 1, 2 (số kênh hiển thị bên cạnh logo) |
| `on-sports.svg` | ON Football / ON Sports / ON Sports News |
| `vtvcab.svg` | VTVcab |
| `vtv.svg` | VTV5... (số kênh hiển thị bên cạnh logo) |
| `htv.svg` | HTV Thể Thao |
| `sctv.svg` | SCTV15... (số kênh hiển thị bên cạnh logo) |

Chưa có file nào thì trang tự hiện tên kênh bằng chữ như cũ.
